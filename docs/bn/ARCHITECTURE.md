## প্রজেক্ট কম্পোনেন্ট

### service/ — বিজনেস API সার্ভিস

WeChat মিনি-প্রোগ্রাম ও Flutter APP-এর জন্য সব বিজনেস API প্রদান করে। webman v2, পোর্ট 8787।

**মডিউল বিভাজন:**

| মডিউল | পাথ | অথেনটিকেশন | বিবরণ |
|------|------|------|------|
| পাবলিক API | `api/` | নেই | লগইন/রেজিস্ট্রেশন/ভেরিফিকেশন কোড/WeChat কলব্যাক |
| ব্যবহারকারী মডিউল | `user/` | JWT | প্রোফাইল/ঠিকানা/ফেভারিট/ফিডব্যাক/প্রমোশন |
| টেকনিশিয়ান মডিউল | `technician/` | JWT+টেকনিশিয়ান | প্রোফাইল/শিডিউল/ওয়ার্কবেঞ্চ/ভেরিফিকেশন/মেম্বার/আয়/উত্তোলন |
| সার্ভিস মডিউল | `service/` | মিশ্র | ক্যাটাগরি/আইটেম/সার্চ/শাখা |
| অর্ডার মডিউল | `order/` | JWT | কার্ট/অর্ডার/পেমেন্ট/রিফান্ড/ভেরিফিকেশন/রিভিউ (OrderController বিজনেস ডোমেইন অনুযায়ী ১০টি trait-এ ভাগ, রাউট ও মেথড নাম অপরিবর্তিত) |
| মার্কেটিং মডিউল | `marketing/` | JWT | কুপন/মেম্বার কার্ড(টাইম কার্ড)/পয়েন্ট/গিফট কার্ড/মেম্বার সুবিধা |
| ওয়ালেট মডিউল | `wallet/` | JWT | ব্যালেন্স/রিচার্জ/লেনদেন/ব্যালেন্স পেমেন্ট |
| কনটেন্ট মডিউল | `content/` | মিশ্র | ব্যানার/বিজ্ঞপ্তি/নোটিফিকেশন |
| LBS মডিউল | `lbs/` | পাবলিক | শহর/কাছের শাখা |

### admin/ — ম্যানেজমেন্ট ব্যাকএন্ড

PC ম্যানেজমেন্ট ব্যাকএন্ড। webman v2 + Flutter Web, পোর্ট 8787।

**বিদ্যমান মডিউল:** অথেনটিকেশন, ড্যাশবোর্ড, ব্যবহারকারী ম্যানেজমেন্ট, রোল পারমিশন, সিস্টেম কনফিগ, অপারেশন লগ, ফাইল আপলোড, সিকিউরিটি প্রোটেকশন

**মডেল বণ্টন:** `admin/app/model/`-এ শুধু ৬টি বিশেষ মডেল রাখা আছে (AdminPermission/AdminRole/AdminUser/OperationLog/OperationLogDetail/SystemConfig), বাকি মডেল composer psr-4 (`app\model\` → `../service/app/model/`) দিয়ে service সংস্করণ শেয়ার করে, দ্বৈত মডেল ড্রিফট এড়ায়; `support\Model` বেস ক্লাস service-এর সাথে সামঞ্জস্যপূর্ণ, `UserPointsExchange::user()` রিলেশন মেথড service সংস্করণ মডেলে একীভূত।

**এক্সটেনশন মডিউল:** টেকনিশিয়ান ম্যানেজমেন্ট, মেম্বার ম্যানেজমেন্ট, শাখা ম্যানেজমেন্ট, সার্ভিস/পণ্য ম্যানেজমেন্ট, অর্ডার ম্যানেজমেন্ট, কুপন, মেম্বার কার্ড, উত্তোলন অডিট, রিভিউ ম্যানেজমেন্ট, রিপোর্ট স্ট্যাটিস্টিক্স, ফাইন্যান্স ম্যানেজমেন্ট, কনটেন্ট ম্যানেজমেন্ট, সিস্টেম সেটিং

## মূল কম্পোনেন্ট

### Snowflake ID

সব প্রাইমারি কী `erikwang2013/snowflake-php` দিয়ে জেনারেট হয়, BIGINT নন-অটোইনক্রিমেন্ট, ডিস্ট্রিবিউটেড গ্লোবাল ইউনিক গ্যারান্টি দেয়। `service/support/Model::nextId()` প্রসেসের ভেতরে একটি Snowflake ইনস্ট্যান্স পুনরায় ব্যবহার করে, ৬৪টি মডেলের `generateId()` কপি মুছে ফেলা হয়েছে (সবাই বেস ক্লাস ইমপ্লিমেন্টেশন ইনহেরিট করে)।

### Hashids

API রিকোয়েস্ট/রেসপন্সে ID `erikwang2013/hashids` দিয়ে এনকোড হয়, বাইরে hash স্ট্রিং প্রকাশ পায়।

### JWT অথেনটিকেশন

`erikwang2013/jwt-webman` Bearer Token, ৭ দিনের বৈধতা, রিফ্রেশ ও ব্ল্যাকলিস্ট সাপোর্ট।

### ডেটা এনক্রিপশন

- **API স্তর**: `erikwang2013/encryption` সংবেদনশীল ডেটা এনক্রিপ্ট/ডিক্রিপ্ট
- **DB স্তর**: `erikwang2013/encryptable` trait ফিল্ড অটো এনক্রিপ্ট/ডিক্রিপ্ট

### সিকিউরিটি প্রোটেকশন

- `erikwang2013/security-php`: ৩১ ধরনের আক্রমণ ডিটেকশন
- `erikwang2013/poster-php`: সংবেদনশীল অপারেশন র্যান্ডম ভেরিফিকেশন
- লগইন লক: ৫ বার ব্যর্থতায় ১৫ মিনিট লক
- কনকারেন্সি সীমা: সর্বোচ্চ ৩টি বৈধ Token

### API ডকুমেন্টেশন

`hg/apidoc` দিয়ে OpenAPI 3.0 স্পেক ডকুমেন্টেশন জেনারেট হয়, অ্যাডমিন ও ক্লায়েন্ট আলাদা:

| প্রান্ত | ঠিকানা | বিবরণ |
|------|------|------|
| অ্যাডমিন প্রান্ত | `admin/ GET /api/docs` | ম্যানেজমেন্ট ব্যাকএন্ড API (JWT+RBAC) |
| ক্লায়েন্ট প্রান্ত | `service/ GET /api/docs` | বিজনেস API (JWT Bearer) |

ডকুমেন্টেশন পাবলিক অ্যাক্সেসযোগ্য, Swagger UI-তে ইমপোর্ট করে ইন্টারঅ্যাকটিভ API ডক দেখা যায়।

### Elasticsearch

`erikwang2013/webman-scout` মডেল অটো ES-এ সিঙ্ক করে, ফুল-টেক্সট সার্চ সাপোর্ট।

## মিডলওয়্যার এক্সিকিউশন চেইন

### service/ মিডলওয়্যার

```
公开API:  Cors → Security(31种检测) → RateLimit → ApiVersion → Controller
用户API:  Cors → Security → RateLimit → Auth(JWT) → Controller
技师API:  Cors → Security → RateLimit → ApiVersion → Auth → TechnicianAuth → Controller
```

### admin/ মিডলওয়্যার

```
公开API:  Cors → Security → RateLimit → Controller
管理API:  Cors → Security → RateLimit → AdminAuth(JWT) → AdminPermission(RBAC) → OperationLog → Controller
健康检查: Cors → Security → RateLimit → Controller
```

## ডেটা ফ্লো

### রিকোয়েস্ট ফ্লো

```
客户端 → Cors → Security → RateLimit → Auth(JWT) → [TechnicianAuth] → Controller
    → Model(encryptable加解密) → BaseController(hashids编码) → JSON响应
```

### অ্যাপয়েন্টমেন্ট ফ্লো

```
浏览服务 → 选门店/技师/时间 → 提交订单 → Redis锁技师3分钟
    → 微信支付 → 通知技师 → 服务开始 → 服务完成 → 评价 → 订单完成
```
