## 一、ব্যবহারকারী পাশ (WeChat মিনি-প্রোগ্রাম + Flutter APP)

ব্যবহারকারী মিনি-প্রোগ্রাম ও APP ফিচার সম্পূর্ণ অভিন্ন। ইউনিফাইড অ্যাকাউন্ট কাস্টমার/টেকনিশিয়ান পরিচয় স্যুইচ সাপোর্ট করে।

### 1. অথেনটিকেশন

| ফিচার | বিবরণ |
|------|------|
| ফোন নম্বর রেজিস্ট্রেশন | ফোন+ভেরিফিকেশন কোড+পাসওয়ার্ড+পাসওয়ার্ড নিশ্চিতকরণ, রেফারেল কোড সাপোর্ট |
| পাসওয়ার্ড লগইন | নিবন্ধিত ফোন+পাসওয়ার্ড |
| কোড লগইন | নিবন্ধিত ফোন+ভেরিফিকেশন কোড |
| WeChat লগইন | WeChat অথরাইজড লগইন, প্রথমবার ফোন বাইন্ড করতে হবে |
| গেস্ট মোড | ব্রাউজ করা যায় কিন্তু অর্ডার দেওয়া যায় না, অর্ডারে রেজিস্ট্রেশন লাগবে |
| পাসওয়ার্ড ভুলে গেলে | কোড দিয়ে পাসওয়ার্ড পরিবর্তন |
| ব্যবহারকারী চুক্তি/প্রাইভেসি চুক্তি | অ্যাডমিন ব্যাকএন্ডে এডিটযোগ্য, রেজিস্ট্রেশনে দেখানো হয় |
