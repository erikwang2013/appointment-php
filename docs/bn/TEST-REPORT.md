## 2. টেক স্ট্যাক ও টেস্ট ফর্ম

- ব্যাকএন্ড: PHP 8.3 webman, দুটি অ্যাপ (service ইউজার এন্ড / admin ব্যাকএন্ড এন্ড), shared service মডেল

- API অটোমেশন = কন্ট্রোলার লেয়ার ইন্টিগ্রেশন টেস্ট (Request তৈরি করে সরাসরি কন্ট্রোলার মেথড কল, বাস্তব DB হিট, ট্রানজেকশন রোলব্যাক)

### এই রাউন্ডের ফিক্স (tester-php আবিষ্কৃত)

- 【bug】AddressController::show/update/destroy ও FavoriteController::destroy hashids ডিকোড করেনি, hashid কল করলে ৪০৪।
  রুট কজ ফিক্স: `BaseController::decodeId`-তে বিশুদ্ধ সংখ্যা পাস-থ্রু কম্প্যাটিবিলিটি যোগ (hashids ডিকোড না হলে এবং ctype_digit হলে অপরিবর্তিত রিটার্ন),
  পুরো রিপোজিটরির ৮৯টি কল পয়েন্ট ইউনিফাইডভাবে উপকৃত; ৪টি কন্ট্রোলার মেথড এন্ট্রিতে decodeId যোগ। সম্পূর্ণ রিগ্রেশন পাস।
- 【bug】hashids min-length 0 হলে কিছু খালি সংখ্যা ID (যেমন 306) ঠিক অন্য ID-এর বৈধ hashids এনকোডিং হতে পারে,
  decodeId ভুলভাবে অন্য ID-তে ডিকোড করতে পারে (AddressControllerTest মাঝে মাঝে ৪০৪, বহু রাউন্ডে র্যান্ডম রিপ্রোডিউস)।
  রুট কজ ফিক্স: service/admin `config/hashids.php`-এর main কানেকশন `length` 0→8,
  এনকোডিং সবসময় ≥৮ অক্ষর, খালি সংখ্যা ID-এর (<৮ ডিজিট বা ১৬ ডিজিট) সাথে লেন্থ ডিসজয়েন্ট, অ্যাম্বিগুইটি এনকোডিং স্পেস থেকে দূর।
  টানা ৫ রাউন্ড AddressControllerTest চালিয়ে স্থিতিশীল ভেরিফাই, সম্পূর্ণ রিগ্রেশন পাস।
- উত্তোলন গেট দিন হার্ডকোড ২০ তারিখ থেকে `config('withdraw.gate_day')` ইনজেক্টেবল (config/withdraw.php),
  আগের ৪টি "শুধু প্রতি মাস ২০ তারিখ" skip কেস রিফ্লেকশন দিয়ে গেট দিন ইনজেক্ট করে, সারাদিন চালানো যায়, 0 skip।

## 4. API অটোমেশন টেস্ট উপসংহার

- এই প্রজেক্টে আলাদা HTTP লেয়ার টেস্ট স্ক্রিপ্ট নেই; ৭০টি বিদ্যমান টেস্ট ফাইল সব কন্ট্রোলার লেয়ার ইন্টিগ্রেশন টেস্ট (বাস্তব DB),
  ৩৫+ কন্ট্রোলার কভার করে, ইন্টারফেস অটোমেশন টেস্টের সমতুল্য
- টেস্ট কভারেজ ম্যাট্রিক্স §3-এ দেখুন
- **HTTP স্মোক এক্সিকিউট হয়েছে** (২০২৬-০৮-২৬): 8787 অন্য প্রজেক্ট দখল করায়, সাময়িকভাবে service
  `config/process.php` লিসেন 8791-এ বদলে সার্ভিস চালু (৩২ webman worker + websocket + ৪ টাইমার সব [OK]),
 实测 `GET /health` → `{"code":0,"message":"ok"}`、`GET /api/guest/services` → HTTP 200
  স্বাভাবিক JSON (hashids এনকোডেড ID দেখা যায়), তারপর stop করে কনফিগ পুনরুদ্ধার, প্রসেস শূন্য রেসিডিউ
- প্রস্তাব: CI-তে flutter build web → Playwright ব্যাকএন্ড এন্ড মূল পাথ E2E যোগ করা (দেখুন §5)
