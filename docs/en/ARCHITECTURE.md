## System Overview

The Appointment Service System uses a three-client + two-service architecture:

```
┌─────────────────────────────────────────────────────┐
│                    用户终端层                         │
│  ┌──────────────┐  ┌──────────────┐                 │
│  │ 微信小程序     │  │ Flutter APP   │                │
│  │ apps/wechat/  │  │ apps/flutter/ │                │
│  └──────┬───────┘  └──────┬───────┘                 │
│         │     功能等价      │                         │
│         └────────┬─────────┘                         │
│                  │ 客户/技师 身份切换                   │
├──────────────────┼──────────────────────────────────┤
│              业务API层                                 │
│  ┌──────────────┐  ┌──────────────┐                 │
│  │ service/ API  │  │ admin/ API    │                │
│  │ 端口 8787     │  │ 端口 8787     │                │
│  └──────┬───────┘  └──────┬───────┘                 │
│         │                  │                          │
│         └────────┬─────────┘                          │
│                  │ 共享 MySQL/Redis/ES                 │
├──────────────────┼──────────────────────────────────┤
```

## Project Composition

### service/ — Business API Service

Provides all business endpoints for the WeChat Mini Program and Flutter APP. webman v2, port 8787.

**Module breakdown:**

| Module | Path | Auth | Description |
|------|------|------|------|
| Public API | `api/` | None | Login/register/captcha/WeChat callbacks |
| User module | `user/` | JWT | Profile/address/favorites/feedback/referral |
| Technician module | `technician/` | JWT+technician | Profile/schedule/workbench/verification/members/earnings/withdrawals |
| Service module | `service/` | Mixed | Categories/items/search/stores |
| Order module | `order/` | JWT | Cart/place order/pay/refund/verify/review (OrderController split into 10 traits by business domain, routes and method names unchanged) |
| Marketing module | `marketing/` | JWT | Coupons/member cards (session cards)/points/gift cards/member benefits |
| Wallet module | `wallet/` | JWT | Balance/top-up/transaction log/balance payment |
| Content module | `content/` | Mixed | Banners/announcements/notifications |
| LBS module | `lbs/` | Public | Cities/nearby stores |

### admin/ — Admin Dashboard

PC admin dashboard. webman v2 + Flutter Web, port 8787.

**Existing modules:** Authentication, dashboard, user management, role permissions, system config, operation logs, file upload, security protection

**Model distribution:** `admin/app/model/` keeps only 6 app-specific models (AdminPermission/AdminRole/AdminUser/OperationLog/OperationLogDetail/SystemConfig); the rest are shared with service via composer psr-4 (`app\model\` → `../service/app/model/`) to avoid dual-model drift; the `support\Model` base class aligns with service, and the `UserPointsExchange::user()` relationship was merged into the service-side model.

**Extended modules:** Technician management, membership management, store management, service/product management, order management, coupons, member cards, withdrawal review, review management, report statistics, finance, content management, system settings

### apps/ — User-Side Frontend

| Directory | Technology | Platform |
|------|------|------|
| `apps/wechat/` | Native WeChat Mini Program | WeChat |
| `apps/flutter/` | Flutter 3.x + GetX + Dio | iOS + Android |

## Core Components

### Snowflake ID

All primary keys are generated by `erikwang2013/snowflake-php` as BIGINT non-auto-increment, guaranteeing distributed global uniqueness. `service/support/Model::nextId()` reuses a single Snowflake instance per process; the 64 models' `generateId()` duplicates were removed (all inherit the base class implementation).

### Hashids

IDs in API requests/responses are encoded by `erikwang2013/hashids` and exposed externally as hash strings.

### JWT Authentication

`erikwang2013/jwt-webman` Bearer Token, 7-day validity, supports refresh and blacklisting.

### Data Encryption

- **API layer**: `erikwang2013/encryption` encrypts/decrypts sensitive data
- **DB layer**: `erikwang2013/encryptable` trait auto-encrypts/decrypts fields

### Security Protection

- `erikwang2013/security-php`: 31 types of attack detection
- `erikwang2013/poster-php`: random verification for sensitive operations
- Login lockout: 5 failed attempts locks for 15 minutes
- Concurrency limit: at most 3 valid tokens

### API Documentation

`hg/apidoc` generates OpenAPI 3.0 spec documents, separate for admin and client:

| Side | Address | Description |
|------|------|------|
| Admin | `admin/ GET /api/docs` | Admin dashboard API (JWT+RBAC) |
| Client | `service/ GET /api/docs` | Business API (JWT Bearer) |

Documents are publicly accessible and can be imported into Swagger UI for interactive API docs.

### Elasticsearch

`erikwang2013/webman-scout` auto-syncs models to ES, supporting full-text search.

## Middleware Execution Chain

### service/ Middleware

```
公开API:  Cors → Security(31种检测) → RateLimit → ApiVersion → Controller
用户API:  Cors → Security → RateLimit → Auth(JWT) → Controller
技师API:  Cors → Security → RateLimit → ApiVersion → Auth → TechnicianAuth → Controller
```

### admin/ Middleware

```
公开API:  Cors → Security → RateLimit → Controller
管理API:  Cors → Security → RateLimit → AdminAuth(JWT) → AdminPermission(RBAC) → OperationLog → Controller
健康检查: Cors → Security → RateLimit → Controller
```

## Data Flows

### Request Flow

```
客户端 → Cors → Security → RateLimit → Auth(JWT) → [TechnicianAuth] → Controller
    → Model(encryptable加解密) → BaseController(hashids编码) → JSON响应
```

### Appointment Flow

```
浏览服务 → 选门店/技师/时间 → 提交订单 → Redis锁技师3分钟
    → 微信支付 → 通知技师 → 服务开始 → 服务完成 → 评价 → 订单完成
```
