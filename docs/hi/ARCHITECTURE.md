│  │ apps/wechat/  │  │ apps/flutter/ │                │

## परियोजना घटक

### service/ — बिज़नेस API सेवा

वीचैट मिनी प्रोग्राम और Flutter APP के लिए सभी बिज़नेस इंटरफ़ेस प्रदान करता है। webman v2, पोर्ट 8787।

**मॉड्यूल विभाजन:**

| मॉड्यूल | पथ | प्रमाणीकरण | विवरण |
|------|------|------|------|
| सार्वजनिक API | `api/` | कोई नहीं | लॉगिन/पंजीकरण/वेरिफिकेशन कोड/वीचैट कॉलबैक |
| उपयोगकर्ता मॉड्यूल | `user/` | JWT | प्रोफ़ाइल/पता/पसंदीदा/फ़ीडबैक/प्रमोशन |
| तकनीशियन मॉड्यूल | `technician/` | JWT+तकनीशियन | प्रोफ़ाइल/शेड्यूल/वर्कबेंच/वेरिफिकेशन/सदस्य/आय/विड्रॉल |
| सेवा मॉड्यूल | `service/` | मिश्रित | श्रेणियाँ/आइटम/खोज/स्टोर |
| ऑर्डर मॉड्यूल | `order/` | JWT | कार्ट/ऑर्डर/भुगतान/रिफंड/वेरिफिकेशन/समीक्षा (OrderController बिज़नेस डोमेन के अनुसार 10 trait में विभाजित, रूट और विधि नाम अपरिवर्तित) |
| मार्केटिंग मॉड्यूल | `marketing/` | JWT | कूपन/सदस्यता कार्ड(सेशन कार्ड)/पॉइंट्स/गिफ्ट कार्ड/सदस्य अधिकार |
| वॉलेट मॉड्यूल | `wallet/` | JWT | बैलेंस/रिचार्ज/ट्रांज़ैक्शन लॉग/बैलेंस भुगतान |
| सामग्री मॉड्यूल | `content/` | मिश्रित | कैरोसेल/घोषणा/सूचनाएँ |
| LBS मॉड्यूल | `lbs/` | सार्वजनिक | शहर/आस-पास के स्टोर |

### admin/ — प्रबंधन बैकएंड

PC प्रबंधन बैकएंड। webman v2 + Flutter Web, पोर्ट 8787।

**मौजूदा मॉड्यूल:** प्रमाणीकरण, डैशबोर्ड, उपयोगकर्ता प्रबंधन, रोल अनुमतियाँ, सिस्टम कॉन्फ़िगरेशन, ऑपरेशन लॉग, फ़ाइल अपलोड, सुरक्षा सुरक्षा

**मॉडल वितरण:** `admin/app/model/` में केवल 6 विशेष मॉडल रखे गए हैं (AdminPermission/AdminRole/AdminUser/OperationLog/OperationLogDetail/SystemConfig), शेष मॉडल composer psr-4 (`app\model\` → `../service/app/model/`) के माध्यम से service संस्करण साझा करते हैं, दोहरे मॉडल ड्रिफ्ट से बचने के लिए; `support\Model` आधार क्लास service के अनुरूप है, `UserPointsExchange::user()` संबंध विधि service संस्करण मॉडल में समाहित की गई।

**विस्तारित मॉड्यूल:** तकनीशियन प्रबंधन, सदस्य प्रबंधन, स्टोर प्रबंधन, सेवा/उत्पाद प्रबंधन, ऑर्डर प्रबंधन, कूपन, सदस्यता कार्ड, विड्रॉल ऑडिट, समीक्षा प्रबंधन, रिपोर्ट आँकड़े, वित्त प्रबंधन, सामग्री प्रबंधन, सिस्टम सेटिंग्स

## मुख्य घटक

### Snowflake ID

सभी प्राथमिक कुंजियाँ `erikwang2013/snowflake-php` से उत्पन्न होती हैं, BIGINT गैर-ऑटो-इंक्रीमेंट, वितरित वैश्विक अद्वितीयता सुनिश्चित करती हैं। `service/support/Model::nextId()` प्रक्रिया के भीतर एकल Snowflake इंस्टेंस का पुनः उपयोग करता है, 64 मॉडलों की `generateId()` प्रतियाँ हटा दी गई हैं (आधार क्लास कार्यान्वयन एकीकृत रूप से विरासत में मिलता है)।

### Hashids

API अनुरोध/प्रतिक्रिया में ID `erikwang2013/hashids` से एन्कोड होती हैं, बाहरी रूप से hash स्ट्रिंग प्रदर्शित होती है।

### JWT प्रमाणीकरण

`erikwang2013/jwt-webman` Bearer Token, 7 दिन वैधता, रिफ्रेश और ब्लैकलिस्ट समर्थन।

### डेटा एन्क्रिप्शन

- **API स्तर**: `erikwang2013/encryption` संवेदनशील डेटा एन्क्रिप्शन/डिक्रिप्शन
- **DB स्तर**: `erikwang2013/encryptable` trait स्वचालित फ़ील्ड एन्क्रिप्शन/डिक्रिप्शन

### सुरक्षा सुरक्षा

- `erikwang2013/security-php`: 31 प्रकार की आक्रमण पहचान
- `erikwang2013/poster-php`: संवेदनशील ऑपरेशन यादृच्छिक सत्यापन
- लॉगिन लॉक: 5 विफलताएँ → 15 मिनट लॉक
- समवर्ती सीमा: अधिकतम 3 वैध Token

### API दस्तावेज़

`hg/apidoc` OpenAPI 3.0 विनिर्देश दस्तावेज़ उत्पन्न करता है, प्रबंधन पक्ष और क्लाइंट पक्ष अलग:

| पक्ष | पता | विवरण |
|------|------|------|
| प्रबंधन पक्ष | `admin/ GET /api/docs` | प्रबंधन बैकएंड API (JWT+RBAC) |
| क्लाइंट पक्ष | `service/ GET /api/docs` | बिज़नेस API (JWT Bearer) |

दस्तावेज़ सार्वजनिक रूप से सुलभ है, इंटरैक्टिव इंटरफ़ेस दस्तावेज़ देखने के लिए Swagger UI में इम्पोर्ट किया जा सकता है।

### Elasticsearch

`erikwang2013/webman-scout` मॉडल स्वचालित रूप से ES में सिंक करता है, फुल-टेक्स्ट खोज समर्थन।

## मिडलवेयर निष्पादन श्रृंखला

### service/ मिडलवेयर

```
公开API:  Cors → Security(31种检测) → RateLimit → ApiVersion → Controller
用户API:  Cors → Security → RateLimit → Auth(JWT) → Controller
技师API:  Cors → Security → RateLimit → ApiVersion → Auth → TechnicianAuth → Controller
```

### admin/ मिडलवेयर

```
公开API:  Cors → Security → RateLimit → Controller
管理API:  Cors → Security → RateLimit → AdminAuth(JWT) → AdminPermission(RBAC) → OperationLog → Controller
健康检查: Cors → Security → RateLimit → Controller
```

## डेटा प्रवाह

### अनुरोध प्रवाह

```
客户端 → Cors → Security → RateLimit → Auth(JWT) → [TechnicianAuth] → Controller
    → Model(encryptable加解密) → BaseController(hashids编码) → JSON响应
```

### अपॉइंटमेंट प्रवाह

```
浏览服务 → 选门店/技师/时间 → 提交订单 → Redis锁技师3分钟
    → 微信支付 → 通知技师 → 服务开始 → 服务完成 → 评价 → 订单完成
```
