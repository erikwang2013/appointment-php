## खरीद प्रवाह

### सेवा अपॉइंटमेंट प्रवाह (सीधा ऑर्डर)

```
服务详情 → 确认订单(门店/技师/时间/优惠券/备注) → 阅读服务协议
    → 提交订单 → Redis锁技师3分钟 → 微信支付 → 支付成功
    → 通知用户+技师 → 服务时间到 → 技师确认开始
    → 服务完成 → 二维码核销 → 用户评价 → 订单完成
```

### उत्पाद खरीद प्रवाह (कार्ट मोड)

```
产品列表 → 加入购物车 → 购物车确认(改数量/删除)
    → 提交订单 → 支付 → 发货 → 收货 → 完成
```

## ऑर्डर स्टेट मशीन

```
pending(待支付) → paid(已支付) → confirmed(已确认)
    → serving(服务中) → completed(已完成) → reviewed(已评价)

pending → cancelled(已取消)
paid → cancelled
paid → refunding(退款中) → refunded(已退款)
```

## तकनीशियन लॉक तंत्र

उपयोगकर्ता ऑर्डर कन्फर्म पेज में प्रवेश करता है → Redis SETNX 3 मिनट लॉक। बाहर निकलने/टाइमआउट पर मुक्त।

```
SETNX lock:tech:123:2026-05-26-14:00 user_456 EX 180
 → 成功: 继续下单
 → 失败: 技师已被锁定
```

## रिफंड नियम

| शर्त | रिफंड प्रतिशत |
|------|----------|
| ऑर्डर के 15 मिनट के भीतर या शुरुआत से >6 घंटे | 100% |
| शुरुआत से ≤6 घंटे | 90% |
| शुरू हो चुका लेकिन सेवा कन्फर्म नहीं | 80% |
| सेवा शुरुआत कन्फर्म के बाद | 0% (कोई रिफंड नहीं) |

## तकनीशियन विड्रॉल

- हर महीने 20 तारीख को विड्रॉल, T+1 वीचैट वॉलेट में जमा
- वेरिफाइड लेकिन निपटान नहीं: 3 दिन में स्वतः कन्फर्म
- न्यूनतम राशि/आरक्षित राशि/सौ राशि सीमा बैकएंड कॉन्फ़िग

### विड्रॉल प्रवाह

```
申请提现 → poster-php验证 → 后台审核(通过/驳回)
    → 完成提现 → 微信零钱到账 → 生成财务流水
```

### आय प्रकार

| प्रकार | विवरण |
|------|------|
| commission | सेवा कमीशन |
| bonus | बोनस (रिटर्न-कस्टमर/उपस्थिति) |
| penalty | जुर्माना (24h में प्रोफ़ाइल नहीं लिखा) |
| subsidy | सब्सिडी |
| attendance | पूर्ण उपस्थिति पुरस्कार |

### रिटर्न-कस्टमर पुरस्कार

उसी तकनीशियन के साथ 30 दिनों में दूसरी खरीद → बोनस रिकॉर्ड

### सदस्य प्रोफ़ाइल

प्रत्येक ऑर्डर पूर्ण होने के 24h के भीतर प्रोफ़ाइल लिखना अनिवार्य, अन्यथा कोई कमीशन नहीं

## पॉइंट्स डिज़ाइन

- उपभोग से प्राप्त, रेफ़रल से प्राप्त (बैकएंड कॉन्फ़िगर करने योग्य)
- 1:100 पर गिफ्ट कार्ड एक्सचेंज (बैकएंड कॉन्फ़िगर करने योग्य)
- पॉइंट्स ट्रांज़ैक्शन टेबल हर बदलाव + बैलेंस रिकॉर्ड करती है

## सदस्यता कार्ड डिज़ाइन

| प्रकार | बिलिंग | विवरण |
|------|------|------|
| month | दिन के अनुसार | सामान्य मासिक कार्ड |
| vip | दिन के अनुसार | VIP वार्षिक कार्ड |
| times | बार के अनुसार | सेशन कार्ड, सेवा आइटम का स्वतंत्र संयोजन |

सेशन कार्ड: खरीदते समय सेवा संयोजन चुनें (A×3+B×5), हर उपयोग पर संबंधित आइटम 1 बार खर्च। खत्म → used_up, समाप्त → expired।

## पहचान स्विच

```
客户 → 切换技师 → 检查技师档案是否approved
    → 是: active_role=technician, 页面切换
    → 否: 引导入驻申请

技师 → 切换客户 → active_role=customer, 页面切换
```

## नए उपयोगकर्ता पुरस्कार

```
注册 → 生成推荐码 → 有推荐人→创建推广记录
    → 自动发新用户优惠券(Phase 5)
    → 推荐人获积分(被推荐人首单后)
```

## भुगतान डिज़ाइन (वीचैट भुगतान आरक्षित)

```
POST /api/order/pay/{id}
    → 创建支付记录 → 调用微信统一下单(预留WechatPayService)
    → 返回支付参数 → 前端调起支付
    → 微信回调 /api/wechat/notify → 验签 → 更新状态paid
    → 通知用户+技师
```
