## 一、उपयोगकर्ता पक्ष (वीचैट मिनी प्रोग्राम + Flutter APP)

उपयोगकर्ता पक्ष मिनी प्रोग्राम और APP के फ़ीचर बिल्कुल समान हैं। एकीकृत खाता ग्राहक/तकनीशियन पहचान स्विच समर्थन करता है।

### 1. प्रमाणीकरण

| फ़ीचर | विवरण |
|------|------|
| मोबाइल नंबर पंजीकरण | मोबाइल नंबर + वेरिफिकेशन कोड + पासवर्ड + पासवर्ड कन्फर्म, रेफ़रल कोड समर्थन |
| पासवर्ड लॉगिन | पंजीकृत मोबाइल नंबर + पासवर्ड |
| वेरिफिकेशन कोड लॉगिन | पंजीकृत मोबाइल नंबर + वेरिफिकेशन कोड |
| वीचैट लॉगिन | वीचैट प्राधिकरण लॉगिन, पहली बार मोबाइल नंबर बाइंड करना आवश्यक |
| गेस्ट मोड | ब्राउज़ कर सकते हैं, ऑर्डर नहीं; ऑर्डर के लिए पंजीकरण आवश्यक |
| पासवर्ड भूलना | वेरिफिकेशन कोड से पासवर्ड बदलना |
| उपयोगकर्ता समझौता/गोपनीयता समझौता | प्रबंधन बैकएंड से संपादन योग्य, पंजीकरण पर प्रदर्शित |

## 二、प्रबंधन बैकएंड (PC Web)

Flutter Web एकल-पेज एप्लिकेशन, कुल 21 पेज: dashboard/उपयोगकर्ता/रोल/कॉन्फ़िग/लॉग/वेरिफिकेशन/शेड्यूल/सेवा/तकनीशियन/ऑर्डर/कूपन/सदस्य/सेशन कार्ड/घोषणा/FAQ/विड्रॉल/समीक्षा/रिपोर्ट/पर्सनल सेंटर/स्टोर वर्कबेंच।

### 1. होमपेज डैशबोर्ड

- रीयल-टाइम आँकड़े: उपयोगकर्ता संख्या/ऑर्डर कुल/तकनीशियन संख्या/सेवा ऑर्डर संख्या
- लाइन चार्ट: ऑर्डर मात्रा प्रवृत्ति/राशि प्रवृत्ति/नए उपयोगकर्ता/सक्रियता

- इन-ऐप संदेश: नया ऑर्डर सूचना/रिफंड सूचना

### 2. तकनीशियन प्रबंधन

- तकनीशियन सूची: UID/मोबाइल नंबर/नाम/क्षेत्र/पंजीकरण समय खोज

- संचालन: निर्यात/ऊपरी स्तर बदलें/निचला स्तर देखें/पासवर्ड मोबाइल बदलें/शेड्यूल प्रबंधन/तकनीकी सेवा आइटम सेटिंग/पाठ्यक्रम प्रगति देखें
- नया जोड़ें: नाम/लिंग/मोबाइल नंबर/पहचान पत्र/पहचान पत्र फ़ोटो
- जुड़ाव आवेदन ऑडिट
