## 2. तकनीकी स्टैक और परीक्षण रूप

## 4. API स्वचालन परीक्षण निष्कर्ष

- इस परियोजना में स्वतंत्र HTTP-स्तर परीक्षण स्क्रिप्ट नहीं; 70 मौजूदा परीक्षण फ़ाइलें सभी नियंत्रक-स्तर इंटीग्रेशन परीक्षण (वास्तविक DB) हैं,
  35+ नियंत्रक कवर, इंटरफ़ेस स्वचालन परीक्षण के समकक्ष
- परीक्षण कवरेज मैट्रिक्स §3 में
- **HTTP स्मोक निष्पादित** (2026-08-26): 8787 अन्य परियोजना द्वारा कब्जा था, इसलिए अस्थायी रूप से service
  `config/process.php` लिसन को 8791 पर बदलकर सेवा शुरू (32 webman worker + websocket + 4 टाइमर सभी [OK]),
  मापन `GET /health` → `{"code":0,"message":"ok"}`, `GET /api/guest/services` → HTTP 200
  सामान्य JSON (hashids-एन्कोडेड ID दिखती हैं), फिर stop और कॉन्फ़िग पुनर्स्थापित, प्रक्रिया शून्य अवशेष
- CI में flutter build web → Playwright बैकएंड पक्ष महत्वपूर्ण पथ E2E जोड़ने की सिफारिश (देखें §5)

## 6. GO / Rust
