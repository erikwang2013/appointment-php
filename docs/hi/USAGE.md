## सिस्टम कॉन्फ़िगरेशन प्रवाह

### 1. मूल सेटिंग्स
सिस्टम कॉन्फ़िगरेशन → प्लेटफ़ॉर्म नाम/LOGO भरें → हमारे बारे में → ग्राहक सेवा फ़ोन/वेबसाइट/ईमेल → प्लेटफ़ॉर्म समझौता → उपयोगकर्ता समझौता/गोपनीयता समझौता संपादित करें

### 2. स्टोर और सेवाएँ
स्टोर प्रबंधन → नया स्टोर (नाम/पता/निर्देशांक/फ़ोन/समय) → सेवा श्रेणियाँ → श्रेणी बनाएँ → सेवा आइटम → नई सेवा (नाम/कीमत/अवधि/विनिर्देश) → उत्पाद प्रबंधन → नया उत्पाद/कार्ड कूपन

### 3. तकनीशियन जुड़ाव
तकनीशियन APP पक्ष आवेदन → प्रबंधन बैकएंड "तकनीशियन प्रबंधन" ऑडिट → स्वीकृति के बाद तकनीशियन शेड्यूल सेट करे → अपॉइंटमेंट प्राप्त कर सके

### 4. संचालन कॉन्फ़िगरेशन
कैरोसेल → अपलोड + जंप सेटिंग | घोषणा → स्क्रॉलिंग घोषणा जारी | कूपन → नया उपयोगकर्ता कूपन/फुल-रिडक्शन कूपन | सदस्यता कार्ड → मासिक कार्ड/VIP/सेशन कार्ड | कमीशन → तकनीशियन कमीशन दर सेट करें

## उपयोगकर्ता पक्ष प्रवाह

### पंजीकरण लॉगिन
वीचैट खोज/स्कैन → मोबाइल नंबर + वेरिफिकेशन कोड पंजीकरण (रेफ़रल कोड वैकल्पिक) → या वीचैट वन-क्लिक लॉगिन → नए उपयोगकर्ता को स्वतः कूपन मिलता है

### अपॉइंटमेंट सेवा
होमपेज श्रेणी ब्राउज़ → सेवा पर क्लिक कर विवरण → कीमत/समीक्षा देखें → तुरंत अपॉइंटमेंट → स्टोर/तकनीशियन/समय/कूपन चुनें → ऑर्डर कन्फर्म → वीचैट भुगतान → भुगतान सफल

### ऑर्डर प्रबंधन
भुगतान शेष: भुगतान पूरा करें | भुगतान किया: सेवा की प्रतीक्षा | पूर्ण: समीक्षा (स्टार + पाठ + छवि) | रिफंड: स्वचालित रूप से रिफंड प्रतिशत गणना

### पर्सनल सेंटर
ऑर्डर/कूपन/सदस्यता कार्ड/पॉइंट्स/पसंदीदा | प्रमोशन सेंटर: प्रमोशन QR कोड प्राप्त करें पॉइंट्स पाएँ | फ़ीडबैक: पाठ + छवि

## तकनीशियन पक्ष संचालन

### पहचान स्विच
APP "मेरा" → तकनीशियन स्विच करें → वर्कबेंच

### दैनिक कार्य
- **शेड्यूल सेटिंग**: दिन के अनुसार अपॉइंटमेंट समय स्लॉट सेट करें
- **अपॉइंटमेंट देखें**: आज के बुक ऑर्डर सूची
- **QR कोड वेरिफिकेशन**: उपयोगकर्ता QR कोड स्कैन कर सेशन वेरिफाई करें
- **सदस्य प्रोफ़ाइल**: हर ऑर्डर के 24h के भीतर ग्राहक प्रोफ़ाइल भरें (टाइमआउट पर कोई कमीशन नहीं)
- **उपस्थिति चेक-इन**: चेक-इन/चेक-आउट/स्वच्छता फ़ोटो

### आय
आज की आय/इन-फ्लाइट फंड/बैलेंस देखें → हर महीने 20 तारीख को विड्रॉल → T+1 वीचैट वॉलेट में

### ग्रोथ
प्रशिक्षण पाठ्यक्रम सीखें → परीक्षा में भाग लें → पास करने पर तकनीशियन लेवल अपग्रेड (कमीशन दर प्रभावित)
