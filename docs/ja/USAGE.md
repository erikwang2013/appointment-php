## システム設定フロー

### 1. 基本設定
システム設定 → プラットフォーム名/LOGO を入力 → 会社概要 → カスタマーサービス電話/公式サイト/メール → プラットフォーム規約 → ユーザー規約/プライバシー規約を編集

### 2. 店舗とサービス
店舗管理 → 店舗を追加（名称/住所/座標/電話/時間）→ サービス分類 → 分類を作成 → サービス項目 → サービスを追加（名称/価格/所要時間/規格）→ 商品管理 → 商品/カード券を追加

### 3. スタッフ参入
スタッフAPP側で申請 → 管理バックエンド「スタッフ管理」で審査 → 承認後スタッフがシフトを設定 → 予約を受け付け可能

### 4. 運営設定
カルーセル画像 → アップロード+ジャンプ先を設定 | お知らせ → スクロールお知らせを公開 | クーポン → 新規ユーザー券/満減クーポンを作成 | 会員カード → 月額カード/VIP/回数券 | 歩合 → スタッフの歩合率を設定

## ユーザー端フロー

### 登録・ログイン
微信で検索/QRコードスキャン → 携帯番号+認証コードで登録（紹介コード任意）→ または微信ワンタップログイン → 新規ユーザーは自動的にクーポンを獲得

### 予約サービス
ホームで分類を閲覧 → サービスをタップして詳細へ → 価格/評価を確認 → 今すぐ予約 → 店舗/スタッフ/時間/クーポンを選択 → 注文を確認 → 微信支払い → 支払い成功

### 注文管理
支払い待ち: 支払いを完了 | 支払い済み: サービスを待つ | 完了済み: 評価（星+テキスト+画像）| 返金: 返金比率を自動計算

### マイページ
注文/クーポン/会員カード/ポイント/お気に入り | 紹介センター: 紹介QRコードを取得してポイント獲得 | 意見フィードバック: テキスト+画像

## スタッフ端の操作

### 身分切替
APP「マイ」→ スタッフに切替 → ワークベンチ

### 日常業務
- **シフト設定**: 日ごとに予約可能な時間帯を設定
- **予約確認**: 今日の予約済み注文リスト
- **QR核销**: ユーザーのQRコードをスキャンして回数を核销
- **会員カルテ**: 各注文の24時間以内に顧客カルテを記入（超過すると歩合なし）
- **勤怠チェックイン**: 出勤/退勤/衛生写真

### 収益
今日の収入/移動中資金/残高を確認 → 毎月20日に出金 → T+1で微信零錢に到着

### 成長
研修コースを学習 → 試験に参加 → 合格でスタッフレベルをアップグレード（歩合率に影響）

## スケジュールタスク

| タスク | 頻度 | 説明 |
|------|------|------|
| 注文自動キャンセル | 30秒 | 支払い待ちが30分超過 |
| 収益自動精算 | 3日 | 完了注文の歩合を精算 |
| クーポン期限切れ | 毎日 | expired をマーク |
| 会員カード期限切れ | 毎日 | expired をマーク |

---

## 返金ルール

| 条件 | 比率 |
|------|------|
| 注文から15分以内または開始まで>6h | 100% |
| 開始まで≤6h | 90% |
| 開始済みで未確認 | 80% |
| 開始確認後 | 0% |
