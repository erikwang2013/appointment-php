# 사용 설명

## 관리 백엔드 로그인

기본 관리자: `admin` / `admin123` | 주소: `http://localhost:8787`

> 최초 로그인 후 비밀번호를 즉시 변경

---

## 시스템 설정 프로세스

### 1. 기본 설정
시스템 설정 → 플랫폼 이름/LOGO 입력 → 회사 소개 → 고객센터 전화/홈페이지/이메일 → 플랫폼 약관 → 사용자 약관/개인정보 약관 편집

### 2. 매장과 서비스
매장 관리 → 매장 추가(이름/주소/좌표/전화/시간) → 서비스 분류 → 분류 생성 → 서비스 항목 → 서비스 추가(이름/가격/시간/규격) → 상품 관리 → 상품/카드 추가

### 3. 기술자 입점
기술자 APP단말 신청 → 관리 백엔드 「기술자 관리」 심사 → 승인 후 기술자가 스케줄 설정 → 예약 수신 가능

### 4. 운영 설정
배너 → 업로드+점프 설정 | 공지 → 스크롤 공지 발행 | 쿠폰 → 신규 사용자 쿠폰/만 N 원 쿠폰 생성 | 멤버십 카드 → 월간 카드/VIP/횟수권 | 수수료 → 기술자 수당 비율 설정

## 사용자단말 프로세스

### 가입 로그인
위챗 검색/QR 스캔 → 휴대폰 번호+인증코드 가입(추천 코드 선택) → 또는 위챗 원클릭 로그인 → 신규 사용자 쿠폰 자동 지급

### 예약 서비스
홈에서 분류 둘러보기 → 서비스 클릭해 상세 진입 → 가격/평가 확인 → 바로 예약 → 매장/기술자/시간/쿠폰 선택 → 주문 확인 → 위챗 결제 → 결제 성공

### 주문 관리
결제 대기: 결제 완료 | 결제됨: 서비스 대기 | 완료: 평가(별점+텍스트+이미지) | 환불: 자동 환불 비율 계산

### 마이페이지
주문/쿠폰/멤버십 카드/포인트/즐겨찾기 | 홍보 센터: 홍보 QR 코드로 포인트 획득 | 의견 피드백: 텍스트+이미지

## 기술자단말 조작

### 신원 전환
APP「마이」→ 기술자 전환 → 작업대

### 일상 업무
- **스케줄 설정**: 날짜별 예약 가능 시간대 설정
- **예약 조회**: 오늘 예약된 주문 목록
- **QR 검증**: 사용자 QR 코드 스캔해 횟수 검증
- **회원 프로필**: 주문별 24h 내 고객 프로필 작성(시간 초과 시 수당 없음)
- **근태 체크인**: 출근/퇴근 체크인/위생 사진

### 수익
오늘 수입/진행 중 자금/잔액 조회 → 매월 20일 출금 → T+1 영점 지갑 입금

### 성장
교육 강좌 수강 → 평가 응시 → 통과 시 기술자 등급 승급(수수료율에 영향)

## 푸시 설정

## 예약 작업

| 작업 | 빈도 | 설명 |
|------|------|------|
| 주문 자동 취소 | 30초 | 결제 대기 30분 초과 |
| 수익 자동 정산 | 3일 | 완료 주문 수당 정산 |

| 멤버십 카드 만료 | 매일 | expired 표시 |
