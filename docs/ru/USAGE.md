## Процесс настройки системы

### 1. Базовые настройки
Системная конфигурация → название платформы/LOGO → о нас → телефон поддержки/сайт/почта → соглашение платформы → пользовательское соглашение/политика конфиденциальности

### 2. Филиалы и услуги
Управление филиалами → добавить филиал (название/адрес/координаты/телефон/время) → категории услуг → создать категорию → позиции услуг → добавить услугу (название/цена/длительность/спецификации) → управление товарами → добавить товар/карту

### 3. Вступление мастеров
Заявка в APP мастера → проверка в админке «Управление мастерами» → после одобрения мастер настраивает расписание → может принимать записи

### 4. Операционные настройки
Карусель → загрузка + настройка перехода | объявления → публикация бегущей строки | купоны → создание купонов для новых пользователей/скидок при достижении суммы | карты участника → месяц/VIP/посещения | комиссия → настройка процента вознаграждения мастера

## Процессы пользовательской части

### Регистрация и вход
Поиск/сканирование в WeChat → регистрация по телефону + коду подтверждения (код приглашения опционален) → или вход в один клик через WeChat → новому пользователю автоматически выдается купон

### Запись на услугу
На главной просмотр категорий → нажать услугу и открыть детали → посмотреть цену/отзывы → записаться → выбрать филиал/мастера/время/купон → подтвердить заказ → оплата WeChat → оплата успешна

### Управление заказами
Ожидает оплаты: завершить оплату | Оплачен: ожидание услуги | Завершён: отзыв (звёзды + текст + фото) | Возврат: доля возврата рассчитывается автоматически

### Личный кабинет
Заказы/купоны/карты участника/бонусы/избранное | Центр продвижения: получить QR-код продвижения и бонусы | Обратная связь: текст + фото

## Работа мастера

### Смена роли
В APP «Мой профиль» → переключиться на мастера → рабочее место

### Ежедневная работа
- **Настройка расписания**: указать доступные слоты записи по дням
- **Просмотр записей**: список заказов на сегодня
- **Подтверждение по QR**: сканировать QR-код пользователя для списания посещения
- **Анкеты участников**: заполнять анкету клиента в течение 24ч после каждого заказа (при задержке комиссия не начисляется)
- **Отметка посещаемости**: приход/уход/фото санитарного состояния

### Доход
Просмотр дохода за день/средств в пути/баланса → вывод средств 20-го числа каждого месяца → зачисление в кошелёк WeChat T+1

### Развитие
Обучение на курсах → участие в аттестации → повышение уровня мастера после прохождения (влияет на ставку комиссии)

## Плановые задачи

| Задача | Частота | Описание |
|------|------|------|
| Автоматическая отмена заказа | 30 секунд | Оплата не поступила более 30 минут |
| Автоматический расчёт дохода | 3 дня | Расчёт комиссии за завершённые заказы |
| Истечение купонов | ежедневно | Пометка expired |
| Истечение карт участника | ежедневно | Пометка expired |

---

## Правила возврата

| Условие | Доля |
|------|------|
| В течение 15 минут после оформления или более чем за 6ч до начала | 100% |
| Менее 6ч до начала | 90% |
| Началось, но не подтверждено | 80% |
| После подтверждения начала | 0% |
