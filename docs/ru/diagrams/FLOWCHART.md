## 1. Процесс записи на услугу

```mermaid
flowchart TD
    A["Пользователь просматривает услуги"] --> B["Выбор филиала/мастера/времени"]
    B --> C["Заполнение примечания"]
    C --> D{"Выбрать купон?"}
    D -->|"использовать"| E["Списание суммы купоном"]
    D -->|"не использовать"| F["Заказ по исходной цене"]
    E --> G["Расчёт цены при заказе (без списания)<br/>PriceCalculator чистое вычисление<br/>купон fixed/percent + карта times<br/>min_amount на основе исходной цены"]
    F --> G
    G --> H["Чтение сервисного соглашения"]
    H --> I["Отправка заказа"]
    I --> J{"Блокировка мастера Redis<br/>SETNX 3 минуты"}
    J -->|"блокировка успешна"| K["Создание заказа pending"]
    J -->|"уже заблокирован"| L["Сообщение: мастер занят"]
    K --> M{"Сумма к оплате?"}
    M -->|"ноль"| N["FREE напрямую<br/>transaction_id = 'FREE'+платёжный номер<br/>заказ → paid"]
    M -->|"оплата с баланса"| B1["Списание баланса кошелька<br/>запись wallet_txn<br/>заказ → paid"]
    M -->|"сумма > 0"| O{"Способ оплаты"}
    O -->|"WeChat"| OW["Вызов WeChat Pay<br/>pay_lock против повторной оплаты"]
    O -->|"баланс"| B1
    OW --> P{"Результат оплаты"}
    B1 --> S
    P -->|"успех"| Q["Потребление колбэка об оплате<br/>markOrderPaid единая точка потребления<br/>атомарное списание купона/карты<br/>заказ → paid"]
    P -->|"сбой/отмена"| R["Заказ остаётся pending<br/>автоматическая отмена через 15 минут"]
    N --> S["Мастер подтверждает начало услуги"]
    Q --> S
    S --> T["Заказ → serving"]
    T --> U["Услуга завершена"]
    U --> V["Мастер списывает по QR-коду"]
    V --> W["Заказ → completed"]
    W --> X["Отзыв пользователя (текст + изображения)"]
    X --> Y["Заказ → reviewed ✅"]

    style A fill:#e3f2fd,stroke:#1565c0,color:#333
    style Y fill:#c8e6c9,stroke:#2e7d32,color:#333
    style L fill:#ffcdd2,stroke:#c62828,color:#333
    style R fill:#fff9c4,stroke:#f9a825,color:#333
    style N fill:#c8e6c9,stroke:#2e7d32,color:#333
```

## 2. Процесс оплаты и возврата

```mermaid
flowchart TD
    subgraph 支付流程["Процесс оплаты (прямой)"]
        P1["Создание записи оплаты"] --> P2["Единый заказ WeChat<br/>pay_lock против конкурентности<br/>out_trade_no = order_no идемпотентно"]
        P2 --> P3["Фронтенд инициирует оплату<br/>выбор способа"]
        P3 -->|"баланс"| PB["Списание баланса кошелька<br/>запись wallet_txn<br/>идемпотентно, списывается один раз"]
        P3 -->|"WeChat"| P4["Колбэк WeChat notify"]
        P4 --> P5["Проверка подписи пройдена"]
        PB --> P6["markOrderPaid идемпотентно<br/>купон/карта списываются только здесь"]
        P5 --> P6
        P6 --> P7["Заказ → paid<br/>уведомление пользователя + мастера"]
    end

    subgraph 退款流程["Процесс возврата"]
        R1["Пользователь запрашивает возврат<br/>refund_lock против конкурентности"] --> R2{"Оценка по правилам возврата"}
        R2 -->|"заказ ≤15мин или до начала >6ч"| R3["Возврат 100%"]
        R2 -->|"до начала ≤6ч"| R4["Возврат 90%"]
        R2 -->|"начато без подтверждения"| R5["Возврат 80%"]
        R2 -->|"после подтверждения услуги"| R6["Возврата нет"]
        R3 --> R7["Заказ → refunding"]
        R4 --> R7
        R5 --> R7
        R7 --> R8["Двухуровневое одобрение<br/>руководитель филиала → финансы"]
        R8 --> R9["Двухэтапный возврат<br/>в транзакции создаётся запись возврата<br/>вне транзакции IO возврата WeChat"]
        R9 -->|"сбой WeChat"| R10["Откат заказа в PAID<br/>повторная попытка возврата"]
        R9 -->|"возврат успешен"| R11["Заказ → refunded<br/>WeChat возврат на исходный канал / зачисление на баланс<br/>возврат купона + удержание баллов"]
    end

    style P6 fill:#c8e6c9,stroke:#2e7d32,color:#333
    style R6 fill:#ffcdd2,stroke:#c62828,color:#333
    style R11 fill:#c8e6c9,stroke:#2e7d32,color:#333
    style R10 fill:#fff9c4,stroke:#f9a825,color:#333
```

## 3. Процесс вывода средств мастера

```mermaid
flowchart TD
    A["Мастер запрашивает вывод средств"] --> B{"poster-php<br/>верификация операции"}
    B -->|"верификация пройдена"| C{"Проверка условий вывода"}
    B -->|"верификация не пройдена"| X["Отказ в операции"]
    C -->|"20-е число месяца"| D["Создание записи вывода"]
    C -->|"не день вывода"| Y["Сообщение: вывод возможен 20-го числа"]
    D --> E["Проверка в админке"]
    E --> F{"Результат проверки"}
    F -->|"одобрено"| G["Выполнение вывода"]
    F -->|"отклонено"| H["Возврат заявки<br/>с причиной отклонения"]
    G --> I["WeChat перевод на кошелёк"]
    I --> J["Зачисление T+1"]
    J --> K["Создание финансовой операции<br/>запись доходов/расходов"]

    style K fill:#c8e6c9,stroke:#2e7d32,color:#333
    style X fill:#ffcdd2,stroke:#c62828,color:#333
    style Y fill:#fff9c4,stroke:#f9a825,color:#333
    style H fill:#ffcdd2,stroke:#c62828,color:#333
```

## 4. Процесс переключения роли

```mermaid
flowchart TD
    A["Текущая роль: клиент"] --> B["Нажатие «переключить на мастера»"]
    B --> C{"Статус профиля мастера"}
    C -->|"approved"| D["active_role = technician<br/>интерфейс переключается на рабочий стол мастера"]
    C -->|"не вступил/на проверке"| E["Направление на заявку вступления"]
    E --> F["Заполнение данных мастера<br/>имя/пол/телефон<br/>удостоверение/фото"]
    F --> G["Отправка на проверку"]
    G --> H{"Проверка в админке"}
    H -->|"одобрено"| D
    H -->|"отклонено"| I["Исправление и повторная отправка"]

    J["Текущая роль: мастер"] --> K["Нажатие «переключить на клиента»"]
    K --> L["active_role = customer<br/>интерфейс переключается на клиентский"]

    style D fill:#c8e6c9,stroke:#2e7d32,color:#333
    style L fill:#c8e6c9,stroke:#2e7d32,color:#333
```

## 5. Процесс пополнения кошелька / зачисления подарочной карты

```mermaid
flowchart TD
    A["Пользователь пополняет / активирует подарочную карту"] --> B{"Способ зачисления"}
    B -->|"пополнение WeChat"| C["Колбэк WeChat Pay<br/>запись wallet_recharge<br/>идемпотентное зачисление"]
    B -->|"активация подарочной карты"| D["GiftCard redeem списывает код карты<br/>сумма зачисляется на баланс кошелька"]
    C --> E["Баланс кошелька увеличивается<br/>запись wallet_txn"]
    D --> E
    E --> F["Оплата заказа с баланса<br/>или возврат на баланс"]
    F --> G["Зачисление/возврат завершены ✅"]

    style G fill:#c8e6c9,stroke:#2e7d32,color:#333
```
